# Heart-Turple ❤️

A simple Python graphics project that creates a heart-shaped pattern using Turtle Graphics and mathematical equations. The design displays the text **"I love you"** in pink on a black background.

## Overview

Heart-Turple uses Python's `turtle` and `math` modules to calculate coordinates along a heart-shaped curve and render a repeated text pattern. It demonstrates how mathematical functions can be used to create visual designs with Python.

## Features

- Heart-shaped pattern generated using mathematical equations
- Pink "I love you" text on a black background
- Trigonometric functions for calculating heart coordinates
- Nested loops to generate the design at multiple scales
- Simple graphical interface using Turtle Graphics

## Technologies Used

- **Python 3**
- **Turtle** — for graphical rendering
- **Math** — for trigonometric calculations

## Prerequisites

- Python 3 installed on your computer
- A desktop environment that supports Turtle Graphics

No third-party packages are required.

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/heart-turple.git
```

### 2. Navigate to the Project Directory

```bash
cd heart-turple
```

### 3. Run the Program

```bash
python heart.py
```

On Windows, you can also use:

```bash
py heart.py
```

A graphics window will open and display the heart-shaped text design.

## How It Works

1. Initializes a Turtle graphics screen with a black background.
2. Sets the drawing text color to light pink.
3. Uses mathematical equations involving sine and cosine to calculate heart-shaped coordinates.
4. Iterates through multiple scale values to create the repeated heart pattern.
5. Writes "I love you" at each calculated coordinate.
